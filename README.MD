BASIC CONTROL FOR PLATFORM 2D

//--------------------------//

This game was created by a team of three.

Main Objective:
Navigate through the maze while avoiding traps and enemies, leading up to a boss fight. The game features basic movement mechanics:

+ WASD to move
+ CTRL to activate an invincible shield for 3 seconds
+ SHIFT to dash a short distance in the movement direction

Try the game at: https://drive.google.com/file/d/1Nu_QZyKyhygSWYsRNJMGwEGTo4ET0tpD/view?usp=sharing

This is the first game I created when I started learning Unity, with the help of two friends who contributed to the idea and development process. Since this is our first project, there are still many bugs we couldn't fix, but it marks an important milestone in my journey. It serves as a reminder to improve and create even better projects in the future.
